# 个人工作台 · Personal Workbench

一个**双击就能用**的单页工作台：空间 / 项目 / 任务 / 产出物 / 复盘，全部跑在你自己的浏览器里。
没有服务器、没有账号、没有网络请求、没有构建步骤——一个文件夹，拷到哪儿都能开。

视觉语言：**工程蓝图 × 瑞士编辑部**（暖纸底 + 蓝图网格 + 朱砂红强调 + 等宽刻度）。

---

## 一、怎么打开

**方式一（推荐）**：在访达 / 资源管理器里找到 `index.html`，**双击**。

**方式二**：浏览器里 `文件 → 打开文件…`，选择 `index.html`。

**方式三**（若你偏好本地服务器，非必需）：

```bash
cd personal-workbench
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

> 已在 Chrome / Safari 最新版验证。工程不使用 ES Module、不加载任何外部 CDN，
> 因此 `file://` 协议下不会触发 CORS 拦截，双击即可正常运行。
>
> 唯一的建议：**把整个 `personal-workbench` 文件夹保持完整**（`index.html` + `assets/` + `js/`），
> 不要只把 `index.html` 单独拷走。

首次打开会自动灌入一套贴合真实场景的**示例数据**（5 个空间、11 个项目、32 条任务、14 件产出物）。
想从零开始，去 **设置 → 数据管理 → 清空全部数据**。

## 二、数据存在哪里

| 项目 | 说明 |
| --- | --- |
| 存储位置 | 浏览器 `localStorage` |
| 键名 | `wb.workbench.v1` |
| 作用域 | **按浏览器 + 按目录**隔离。换浏览器、换电脑、换文件夹，数据不共享 |
| 上传行为 | 无。全部数据只在本机，代码里没有任何 `fetch` / `XMLHttpRequest` 出网请求 |

### 重要提醒

- **清理浏览器数据 / 无痕窗口关闭 = 数据消失。** 请养成定期备份的习惯。
- 同一浏览器打开多个标签页时，一个页面改了数据，另一个会自动同步刷新。

## 三、备份与迁移

### 导出备份

- 左下角 **「备份数据」** 按钮，或
- **设置 → 数据管理 → 导出 JSON**，或
- 命令面板（`⌘K`）输入「导出」

会下载一个 `workbench-backup-YYYY-MM-DD.json`，里面是全部数据的完整快照。

### 恢复 / 迁移到另一台电脑

1. 在新电脑上打开 `index.html`
2. **设置 → 数据管理 → 导入 JSON**，选择备份文件
3. 确认覆盖（会二次确认，防误操作）

### 建议节奏

每周复盘（生成周报）之后顺手导出一次，把 JSON 丢进你的云盘或 Git 仓库。
一年 52 个文件，占不到 5 MB，却是你全年工作的完整底稿。

## 五、任务快速输入语法

任务视图顶部（以及仪表盘「今日待办」卡片底部）有一行快速添加框，支持一行成事：

```
下周一前出完商用多联机选型对比表 #青岛万象城 !P0 @周一 ~90
```

| 语法 | 含义 | 示例 |
| --- | --- | --- |
| `#项目名` | 关联项目（模糊匹配，自动带出所属空间） | `#青岛万象城` |
| `!P0` / `!P1` / `!P2` | 优先级 | `!P0` |
| `@日期` | 截止日期，支持 `今天` `明天` `后天` `周一`~`周日` `本周五` `3-25` `2026-03-25` | `@明天` |
| `~分钟` | 预估耗时（分钟） | `~90` 或 `~90min` |
| 其余文字 | 任务标题 | |

输入过程中下方会**实时预览**解析结果（项目 / 优先级 / 日期 / 耗时各自高亮），确认无误按回车。

## 六、每日使用

这套工作台为"每天打开"而设计，每天首次启动会自动完成一次**日滚**（`WB.App.dailyRefresh()`，在首屏渲染前执行）：

- **识别新的一天**：对比 `settings.lastActiveDate` 与今天，跨天时触发日滚逻辑；同日多次打开是 no-op（幂等），天然防多标签页重复滚。
- **连续活跃天数更新**（决策表）：
  - 昨天打开过 → `streak.current += 1`，`streak.best = max(best, current)`
  - 断签多日（上次打开早于昨天）→ `streak.current = 1`（重置）
  - 今天已经打开过 → 不变
- **种子示例任务滚动**：仅未完成的种子任务（`_seed: true`）会按原始偏移 `_seedOffset` 重算 `due`，让"今日待办"始终是今天、"本周重点"始终是本周。隔多少天打开都不会让任务越滚越远（用 `_seedOffset` 重算，不累加 deltaDays）。已完成的种子任务 `completedAt` 不动（历史事实，热力图/周报依赖它）。**用户自建任务（无 `_seed`）的 `due` 绝不会被工作台擅自改动。**
- **日滚日志**：跨天启动会在事件流里追加一条 `daily-roll` 日志「新的一天启动 · streak=N」，可在复盘视图查到。

仪表盘「作战简报」区域也强化了"今日感"：

- **日期块**：display 衬线大字显示今天的月日（如「8月3日」），mono 小字显示星期全称 + 周序（如「星期一 · 第 32 周」），全部 `new Date()` 实时取，不缓存。
- **状态摘要**：动态一句话「今日 N 项待办 · 逾期 N 项待清 · N 项进行中项目 · 本周已交付 N 件 · 连续活跃 N 天」。
- **今日已完成小卡**：显示今天 `completedAt === today` 的任务数，配刻度尺进度（今日已完成数 / 今日相关总数），给人"今天有进展"的反馈。
- **逾期归位**：「今日待办」卡里把逾期任务单独分组、朱砂红标注「逾期 N 项」，和今日项分开渲染，不再混在一起。
- **清闲空状态**：今日既无待办也无逾期时，显示「今日无安排 · 适合深度工作或复盘」+「新建任务」按钮，空状态也好看。

**每天的建议节奏**：

1. 打开后先看仪表盘「作战简报」——日期块、今日已完成进度、连续活跃天数、状态摘要。
2. 看「今日待办」卡——若有逾期分组（朱砂红标注）先清掉或改期，再处理今日项。
3. 工作结束前：勾选完成的任务、为明天补一两件关键事，让明天的"今日待办"先有底。

## 八、将来怎么接飞书 / 乐享

`js/connectors.js` 已经把「连接器」这层抽象好了，接通远端时**不需要动任何视图代码**。

### 现状

```js
WB.Connectors.registry = {
  local:   LocalAdapter,    // 真实实现：读写 localStorage
  lark:    LarkAdapter,     // 桩：接口已预留，尚未接通
  lexiang: LexiangAdapter   // 桩：接口已预留，尚未接通
};
WB.Connectors.active = 'local';
```

四个契约方法（**全部返回 Promise**，桩实现返回 `{ok:false, message:'…接口已预留，尚未接通'}`，不抛异常）：

| 方法 | 作用 |
| --- | --- |
| `listTasks(filter)` | 拉取任务列表 |
| `upsertTask(task)` | 新建 / 更新任务 |
| `listOutputs(filter)` | 拉取产出物列表 |
| `pushOutput(output)` | 推送一件产出物到远端 |
| `testConnection()` | 连通性自检（设置页「测试连接」按钮调用） |

### 接通飞书（Lark）三步走

1. **拿凭证**：在[飞书开放平台](https://open.feishu.cn/)创建企业自建应用，拿到 `App ID` / `App Secret`；
   开通权限：`task:task`（任务）、`bitable:app`（多维表格）、`docx:document`（云文档，可选）。
2. **填配置**：本工作台 **设置 → 连接器 → 飞书**，填入 App ID / App Secret / 任务清单 GUID / 多维表格 App Token，打开开关。
3. **补实现**：打开 `js/connectors.js`，找到 `LarkAdapter`，按注释里的 `TODO` 把 `notWired()` 换成真实请求。
   文件里已经写好了端点与**字段映射表**，例如：

   | 本地字段 | 飞书任务字段 |
   | --- | --- |
   | `title` | `summary` |
   | `note` | `description` |
   | `due` | `due.timestamp`（毫秒） |
   | `status` | `completed_at` 是否为空 |
   | `priority` | 自定义字段 / 富文本前缀 |

   > ⚠️ 注意：`file://` 协议下浏览器直连飞书 API 会被 CORS 拦截，且 `App Secret` 不应放在前端。
   > 生产做法是加一层极薄的本地代理（几十行 Node / Python 即可），前端只与 `http://localhost:xxxx` 通信。
   > `LarkAdapter` 里预留了 `baseUrl` 常量，改成你的代理地址即可。

### 接通乐享（Lexiang）

同理，`LexiangAdapter` 里预留了 MCP 服务地址、Token、Team ID、Space ID 四个配置项，
以及「产出物 → 知识库文档」的字段映射（`title → title`、`note → content`、`tags → knowledge_tags`）。
把 `pushOutput()` 的 `TODO` 换成对乐享写入接口的调用，就能实现「产出物一键归档进知识库」。

### 设计约定

- **本地永远是唯一真实来源（single source of truth）。** 远端只做镜像同步。
- 即使连接器被打开，`upsertTask` / `pushOutput` 也先落本地，再异步推远端。
- 任何远端失败都会 `catch` 回落到本地，**绝不阻塞你的操作**。

## 九、文件结构

```
personal-workbench/
├── index.html              # 骨架 + script 顺序加载（无 ES Module）
├── README.md               # 本文件
├── assets/
│   └── styles.css          # 全部样式：CSS 变量 / 蓝图网格 / 12 列栅格 / 组件 / 动效
└── js/
    ├── ui.js               # WB.Util（纯函数） + WB.UI（DOM/浮层/toast/表单/卡片） + WB.Parts（业务小组件）
    ├── store.js            # WB.Store：数据模型、localStorage 读写、CRUD、统计、导入导出、种子数据
    ├── connectors.js       # WB.Connectors：local 真实实现 + lark / lexiang 预留桩
    ├── view-dashboard.js   # 仪表盘
    ├── view-tasks.js       # 任务（列表 / 看板 / 快速输入语法）
    ├── view-projects.js    # 项目 & 空间（卡片 / 表格 / 抽屉 / 里程碑）
    ├── view-outputs.js     # 产出物库（网格 / 时间轴）
    ├── view-review.js      # 复盘与周报（Markdown / 热力图）
    ├── view-settings.js    # 设置（数据 / 存储 / 快捷入口 / 连接器 / 偏好 / 快捷键）
    └── app.js              # WB.App：路由、命令面板、全局快捷键、启动引导
```

加载顺序（`index.html` 中已固定，勿随意调整）：

```
ui.js → store.js → connectors.js → view-*.js → app.js
```

所有模块用 IIFE 挂到全局 `WB` 命名空间下，互相之间**只在运行时**引用，不存在循环依赖。

## 十、常见问题

**Q：打开是空白页？**
A：按 `F12` 打开控制台看报错。最常见原因是文件夹结构被破坏（`assets/` 或 `js/` 丢了）。

**Q：换了个浏览器数据没了？**
A：`localStorage` 按浏览器隔离。请用「导出 JSON → 在新浏览器导入」迁移。

**Q：能多人协作吗？**
A：这是**单人**工作台，刻意不做协作。要共享，导出 JSON 发给对方即可。

**Q：数据会不会上传？**
A：不会。全工程零网络请求，你可以断网使用。

**Q：怎么恢复示例数据？**
A：**设置 → 数据管理 → 重置为示例数据**（会覆盖当前数据，请先备份）。

## 十一、设计取向说明

- **克制的动效**：只有卡片错峰淡入、数字滚动、进度条绘制三类，全部尊重系统的
  `prefers-reduced-motion` 设置——你开了「减弱动态效果」，它就一动不动。
- **无圆角美学**：2px 圆角、1px 细线、等宽数字，让密集信息保持可读。
- **朱砂红只用于「需要你现在行动」**：逾期、P0、今日到期、活跃状态。其余一律克制。
- **空状态也是设计**：每个空列表都写了一句能推着你动手的话，而不是干巴巴的「暂无数据」。
